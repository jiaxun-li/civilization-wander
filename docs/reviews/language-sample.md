# 语言与文字：两河、埃及简洁样板

本轮完成两河与埃及样板，其他地区尚未扩充。保留现有结构与其余条目，没有新增筛选器或专题数据模型。

## 内容

- 新增苏美尔语、阿卡德语、埃及语，共三个语言身份，不拆方言和朝代。
- 新增僧侣体、世俗体两条文字轨迹；象形文字保持原条目。
- 苏美尔语、阿卡德语先呈现两河南部有依据的使用，不将南部证据复制到所有地区。
- 楔形文字南部使用从早期发展接续到本期范围，保留巴比伦与黎凡特原有条目。
- 所有新条目的前300年是本期收录边界，不是消亡日期；时间说明明确标出，埃及象形文字既有394年终点不改。
- 苏美尔语长带包含口语与后续书写延续，详情明确约前2000年前后退出日常口语；不将整段标作母语使用。
- 埃及语覆盖尼罗河谷与三角洲，僧侣体先录河谷，世俗体录河谷与三角洲。未将条目自动扩展到努比亚。

## 依据与取舍

- Oracc DCCLT: https://oracc.museum.upenn.edu/dcclt/intro/lexical_intro.html — 南部两种语言在第三千纪并存，苏美尔语后续用于书吏与祭仪；起始年取近似历史范围，不是语言诞生年份。
- Met 327385: https://www.metmuseum.org/art/collection/search/327385 — 第三千纪上半叶可以可靠记录苏美尔语；本期采用约前2900年作近似可见历史起点。
- UCL languages: https://www.ucl.ac.uk/museums-static/digitalegypt/sound/index.html — 埃及语与各书写形式。
- UCL writing scope: https://www.ucl.ac.uk/museums-static/digitalegypt/writing/writingscope.html — 早王朝已有僧侣体；世俗体在前8世纪出现，本期采用前7世纪的主要使用范围。
- 起点和地区范围均为概括，不是逐年普查；书写存在不意味着所有居民识字。学术分期、确切口语退出日期仍有不确定性。

## 表现

语言保留粗色带，文字使用轨迹；语言优先排在文字上方。长度足够时显示简称，短条不硬塞文字。保持地区格子的原有宽高，语言颜色不随王朝变化。
